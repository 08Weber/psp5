# PSP5 REMAKE – PSP-launcher

**PSP5 REMAKE** är en fork av [psp5 av 08Weber](https://github.com/08Weber/psp5), vidareutvecklad av **medhatk**.
Den kan köras som homebrew eller som valfri ARK-startmeny på PSP med ARK-4 eller ARK-5.

Huvudflikarna är **Games**, **Apps**, **Library** och **Media**. Under Media finns musik, bilder och video.
Projektet har också spelinformation, hantering av sparfiler, filhanterare, kontrollcenter, viloläge, teman och
utökade systeminställningar.

## Installation

Se den fullständiga [installationsguiden](../INSTALL.md) (på engelska). Hämta senaste versionen från
[Releases](https://github.com/medhatk/PSP5-REMAKE/releases) och välj paketet för din PSP och ARK-version. PSP Go-paket finns, men har ännu inte
verifierats på en riktig PSP Go.

## Funktioner

- Spel och appar visas på egna flikar; Library samlar innehållet.
- Media innehåller musikspelare, bildvisare och MP4-videospelare.
- Kategorier hämtas från mappar i `ISO/` och `PSP/GAME/`, även mappar med ett enda spel.
- HOME öppnar Control Center. Därifrån kan du öppna Standby Screen, filhanteraren och systeminställningar.
- Settings innehåller systeminformation, datum- och tidsformat, CFW-inställningar, pluginhantering och teman.
- PSP5 REMAKE ändrar inte `flash0`; vägen tillbaka till XMB beskrivs i installationsguiden.

## Kontroller

| Knapp | Funktion |
|---|---|
| L / R | Byt mellan Games, Apps, Library och Media |
| Cross | Starta eller välj; spela/pausa musik |
| Square | Alternativ för spel, bibliotek och musik |
| Triangle | Inställningar; album i musikspelaren |
| Circle | Tillbaka |
| SELECT | Välj kategori |
| HOME | Öppna Control Center |
| Vänster / höger i musik | Föregående/nästa låt; håll för att söka |
| Vänster / höger i video | Sök 10 sekunder bakåt/framåt |

PSP Go, olika ARK-versioner och alla funktioner har inte testats på varje modell. Ange PSP-modell och ARK-version
när du rapporterar kompatibilitetsproblem.
